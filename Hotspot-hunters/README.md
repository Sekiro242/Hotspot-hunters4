# Hotspot Hunters

A frontend-only Earth observation prototype: a real MapLibre WebGL globe, a deterministic synthetic thermal record, and connected experiences for regional exploration, time, sensor comparison and scientific interpretation. Independent concept; no NASA endorsement is implied.

## Run

Requires Node.js 22.12+ (tested with Node 24).

```powershell
cd 'F:\Hotspot hunters'
npm install
npm run dev
```

Open http://127.0.0.1:5173. No API key or backend is needed.

```powershell
npm run build
npm run preview
npm test
node tests/browser.mjs
```

The browser test uses installed Google Chrome, expects the development server on port 5173, and saves desktop (1440×900) and mobile (390×844) screenshots in `tests/`.

## Demonstration route

1. Explore the Earth; drag the globe, zoom, or switch projections using the globe button.
2. Choose Amazon Basin through search or the regional story links. Five presets are available.
3. Toggle MODIS / VIIRS, choose detections, clusters or density, and click a point for its native metadata. At global zoom, detections aggregate automatically; zoom in or click an aggregate to inspect records.
4. Open Time. Choose a month in the seasonal ribbon, scrub the timeline, play the annual cycle, change playback speed, or inspect historical and unusual periods.
5. Open Compare. Drag the divider; both maps share one camera. Switch to either sensor alone. Choose a pre-2012 year to inspect the explicit unavailable VIIRS state.
6. Open The Science and advance through four harmonization stages. Expand the methodology notes for definitions, provenance and source links.

## Data and scientific limits

Every observation is synthetic, generated by a seeded function in `src/data/observations.ts`. The adapter exposes year, filtered selection, and monthly aggregation methods. The map, counts and calendar use the same selected records. Dates, coordinates, native sensor confidence, FRP, satellite and day/night are preserved. There is no live fire feed, forecast, calibrated index, or validated harmonization algorithm.

Seasonal shapes are illustrative, not regional findings. The unusual-period rule is explicitly a synthetic monthly count greater than 1.3 times the selected year's monthly mean. Historical views retain source availability differences; these are not comparable calibrated fire totals. Source confidence values are not treated as equivalent.

MODIS is available from 2000 in the demo; VIIRS from 2012. The time machine plays one selected year's monthly windows and loops. All comparison views share date and region; split mode intentionally shows both instruments. A hotspot is not necessarily a confirmed wildfire. Missing observations do not establish absence of fire.

## Rendering and resilience

- MapLibre GL JS 6, React 19, TypeScript and Vite.
- Only one map renderer during ordinary exploration; a second synchronized map is created only for split comparison and destroyed on exit.
- Basemap imagery: Esri World Imagery (credits remain visible in map attribution). Local Natural Earth world geometry renders beneath it and remains usable when external tiles fail.
- Local world geometry: https://github.com/nvkelso/natural-earth-vector (Natural Earth, public domain).
- Google Fonts: Space Grotesk and DM Sans, with system font fallbacks. External imagery and fonts need network access; WebGL/hardware acceleration is required for the map.
- Reduced-motion preferences shorten the entry and camera flights. Navigation, source controls, timeline, calendar and split divider are keyboard accessible. Individual geographic observations are selected by map pointer interaction.

## Structure

`src/App.tsx`: shared selection state and navigation. `src/components/Earth.tsx`: map lifecycle, GPU layers, hit-testing and synchronized cameras. `Calendar.tsx`: seasonal and historical exploration. `Science.tsx`: interactive methodology story. `src/data/observations.ts`: typed adapter and seeded data. `src/styles/main.css`: responsive design and motion.
